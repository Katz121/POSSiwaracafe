## 1 · ข้อความทักทายตอนเพิ่มเพื่อน (Greeting message)

ที่: หน้าหลัก → ข้อความทักทายเพื่อนใหม่ · ไม่กินโควตา 300 ข้อความ/เดือน

```
สวัสดีค่ะ ยินดีต้อนรับสู่ Siwara Cafe
คาเฟ่ในบ้านไม้สักเก่าเกือบร้อยปี ย่านเมืองเก่าตะกั่วป่า

เปิดอังคาร - อาทิตย์ 10:00 - 17:00 น. (ปิดวันจันทร์)

กดเมนูด้านล่างได้เลยค่ะ
· สั่งล่วงหน้า แล้วแวะมารับ ไม่ต้องยืนรอ
· เช็คแต้มสะสมของตัวเอง แค่กรอกเบอร์
· ดูเมนู ราคา และเค้กสั่งทำ
· แผนที่ร้าน กดแล้วนำทางได้ทันที

อยากถามอะไรพิมพ์ทิ้งไว้ได้เลยค่ะ เดี๋ยวเราตอบให้
```

## 2 · ตอบกลับอัตโนมัติตามคีย์เวิร์ด (Auto-reply)

ที่: หน้าหลัก → การตอบกลับอัตโนมัติ → เพิ่มข้อความ · ไม่กินโควตาเช่นกัน
ตั้งไว้ยิ่งเยอะ ยิ่งลดข้อความที่ต้องมานั่งตอบเอง โดยเฉพาะนอกเวลาร้านเปิด

**คีย์เวิร์ด: เปิด, ปิด, กี่โมง, เวลา, วันไหน**
```
ร้านเปิดอังคาร - อาทิตย์ 10:00 - 17:00 น. ค่ะ
ปิดทุกวันจันทร์

กดเมนู "แผนที่ร้าน" ด้านล่างแล้วนำทางมาได้เลยค่ะ
```

**คีย์เวิร์ด: สั่ง, สั่งล่วงหน้า, พรีออเดอร์, จอง**
```
สั่งล่วงหน้าได้ที่เมนู "สั่งล่วงหน้า" ด้านล่างเลยค่ะ
เลือกเมนู ใส่เบอร์โทร แล้วกดสั่ง ทางร้านได้รับออเดอร์ทันที
พอถึงร้านแจ้งชื่อหรือเบอร์ที่สั่งไว้ได้เลย

ใส่เบอร์โทรทุกครั้งนะคะ ระบบจะสะสมแต้มให้อัตโนมัติ
```

**คีย์เวิร์ด: แต้ม, สะสมแต้ม, สมาชิก, ส่วนลด**
```
กดเมนู "สะสมแต้ม" ด้านล่าง แล้วกรอกเบอร์โทร
จะเห็นแต้มของตัวเองทันทีค่ะ ไม่ต้องรอเราตอบ

แต้มผูกกับเบอร์โทร สั่งครั้งไหนใส่เบอร์เดิม แต้มเก็บต่อให้เอง
พอครบตามเกณฑ์ก็แลกเป็นส่วนลดได้เลย
```

**คีย์เวิร์ด: เค้ก, สั่งเค้ก, วันเกิด, เบรค, สแน็คบ็อกซ์**
```
เค้กมีทั้งแบบพร้อมรับหน้าร้านและแบบสั่งทำค่ะ
รับจัดเบรค สแน็คบ็อกซ์ และเค้กวันเกิดด้วย

ดูแบบทั้งหมดที่เมนู "เค้กสั่งทำ" ด้านล่าง
ถูกใจแบบไหน ส่งรูปมาในแชทนี้พร้อมวันที่อยากได้ เดี๋ยวเราเช็คคิวให้ค่ะ
```

**คีย์เวิร์ด: ที่จอดรถ, จอดรถ, ที่จอด**
```
มีลานจอดรถหน้าร้านค่ะ
ถ้าเต็มจอดริมถนนย่านเมืองเก่าได้เหมือนกัน
```

**คีย์เวิร์ด: ที่ไหน, แผนที่, ไปยังไง, พิกัด, ที่อยู่**
```
53 ถนนราษฎร์บำรุง ตะกั่วป่า พังงา 82110 ค่ะ
กดเมนู "แผนที่ร้าน" ด้านล่างแล้วนำทางได้ทันที

โทรสอบถามได้ที่ 097-350-1514
```

**คีย์เวิร์ด: wifi, ไวไฟ, นั่งทำงาน, ปลั๊ก**
```
นั่งทำงานได้สบายค่ะ ร้านเงียบ มีมุมนั่งหลายแบบ
มีบอร์ดเกมให้เล่นด้วยถ้ามากันหลายคน
```
