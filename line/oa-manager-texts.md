# ข้อความที่ต้องไปวางเองใน LINE OA Manager

Messaging API ตั้ง greeting กับ auto-reply ไม่ได้ ต้องทำในเว็บ
`manager.line.biz` → เลือกบัญชี Siwara → การตั้งค่าตอบกลับ

---

## 1 · ข้อความทักทายตอนเพิ่มเพื่อน (Greeting message)

ที่: หน้าหลัก → ข้อความทักทายเพื่อนใหม่

```
สวัสดีค่ะ ยินดีต้อนรับสู่ Siwara Cafe
คาเฟ่ในบ้านไม้สักเก่าเกือบร้อยปี กลางเมืองเก่าตะกั่วป่า

กดเมนูด้านล่างได้เลยค่ะ
· สั่งล่วงหน้า แล้วแวะมารับ ไม่ต้องยืนรอ
· ดูเมนูและราคาทั้งหมด
· เค้กสั่งทำ เลือกแบบแล้วทักมาคุยรายละเอียดได้
· แผนที่ร้าน กดแล้วนำทางได้ทันที

อยากถามอะไรพิมพ์ทิ้งไว้ได้เลยค่ะ เดี๋ยวเราตอบให้
```

หมายเหตุ: greeting ไม่กินโควตา 300 ข้อความ/เดือน

---

## 2 · ตอบกลับอัตโนมัติตามคีย์เวิร์ด (Auto-reply)

ที่: หน้าหลัก → การตอบกลับอัตโนมัติ → เพิ่มข้อความ
ไม่กินโควตาเหมือนกัน · ตั้งไว้ยิ่งเยอะ ยิ่งลดข้อความที่ต้องมานั่งตอบเอง

**คีย์เวิร์ด: เปิด, กี่โมง, เวลา, ปิด**
```
ร้านเปิดทุกวันค่ะ
(ใส่เวลาเปิด-ปิดจริงตรงนี้ก่อนเปิดใช้งาน)

แผนที่ร้านกดที่เมนูด้านล่างได้เลยค่ะ
```
⚠️ ต้องเติมเวลาจริงก่อน ยังไม่มีข้อมูลนี้ในระบบ

**คีย์เวิร์ด: สั่ง, สั่งล่วงหน้า, พรีออเดอร์**
```
สั่งล่วงหน้าได้ที่เมนู "สั่งล่วงหน้า" ด้านล่างเลยค่ะ
เลือกเมนู ใส่เบอร์โทร แล้วกดสั่ง ทางร้านจะได้รับออเดอร์ทันที
พอถึงร้านแจ้งชื่อหรือเบอร์ที่สั่งไว้ได้เลย

ใส่เบอร์โทรทุกครั้ง ระบบจะสะสมแต้มให้อัตโนมัติค่ะ
```

**คีย์เวิร์ด: แต้ม, สะสมแต้ม, สมาชิก**
```
แต้มสะสมผูกกับเบอร์โทรค่ะ
สั่งครั้งไหนใส่เบอร์เดิม แต้มจะเก็บต่อให้เอง
อยากเช็คว่ามีกี่แต้ม พิมพ์เบอร์โทรทิ้งไว้ได้เลย เดี๋ยวเราเช็คให้
```

**คีย์เวิร์ด: เค้ก, สั่งเค้ก, วันเกิด**
```
เค้กมีทั้งแบบพร้อมรับหน้าร้านและแบบสั่งทำค่ะ
ดูแบบทั้งหมดได้ที่เมนู "เค้กสั่งทำ" ด้านล่าง
ถูกใจแบบไหน ส่งรูปมาในแชทนี้ พร้อมวันที่อยากได้ เดี๋ยวเราเช็คคิวให้
```

**คีย์เวิร์ด: ที่จอดรถ, จอดรถ**
```
(ยังไม่มีข้อมูล ใส่เองก่อนเปิดใช้งาน)
```

## 3 · ตรวจก่อนเปิดใช้จริง

- [ ] เติมเวลาเปิด-ปิดจริง กับข้อมูลที่จอดรถ
- [ ] โหมดตอบกลับต้องเป็น "แชท" (ตอบเองได้) ไม่ใช่ "บอท" อย่างเดียว
- [ ] ทดลองแอดเพื่อนด้วยไลน์ส่วนตัว ดูว่า greeting กับริชเมนูขึ้นครบ
- [ ] พิมพ์ `myid` ในแชท เอา id ที่ได้ไปตั้ง `LINE_TARGET_ID` (ดู `line/README.md`)
